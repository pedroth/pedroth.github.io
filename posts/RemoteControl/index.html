Remote Control is a simple project I made to control my Raspberry Pi from my cell phone. It turned out to be a failure for that original goal, but it still works for controlling my computer from my cell phone.

Check out the project below.

Project

Implementation details

Most of the program was vibe coded. I used VS Code, Gemini 3, and ChatGPT. After a few iterations, it was able to produce an initial prototype. The good part was that it got the main architecture right: WebSocket communication, the libraries for controlling the keyboard and mouse, and even some of the more challenging mouse-control logic.

The downside was that it required a lot of manual fixing, testing, and debugging to get right. It also created some redundant files and dependencies. In general, it was not as minimal a codebase as I had requested. The codebase ended up being quite unmaintainable (for me, at least). In the end, I mostly rewrote everything on top of the original prototype.

Overall, it was a good experience, and I don’t think I could have done it without the help of AI (or at least it would have taken me much longer).
