After discovering that phone sensor data can be accessed from the browser[1], I decided to build a project around it. This project is a way to visualize that sensor data. In this demo, you can see a wireframe abstraction of a phone moving in space, with its movement tracing a path.

The sensors used are:

  • Real-time orientation
  • Real-time acceleration

While initially designed for mobile hardware, a desktop version of this demo is also available.
