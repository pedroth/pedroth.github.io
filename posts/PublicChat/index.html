Public Chat is a web chat application that I built to learn about HTTP server features in Java.

My goals with this project were:

  • Learning how to build a java server with minimal dependencies.
  • Learning about setting up a website from home using some tools:
    • The amazing DuckDNS free dynamic DNS.
    • Router port-forwarding.
    • Setting up a Raspberry Pi server.
  • Implementing upload from scratch.
  • Creating a chat with a public delete button.
  • Testing polling HTTP requests to simulate WebSockets (conclusion: just use WebSockets).
  • Creating an open-source project.
  • Dockerizing the app.

The server is ...loading.

Run with Docker

docker run -it -p 80:8080 --name public-chat pedroth/public-chat

Then open localhost. If you want to change the port, just run docker run -it -p :8080 ....

Running Docker on Raspberry Pi

Since Raspberry Pi has an ARM processor, I built a different image:

docker run -it -p 80:8080 --name public-chat pedroth/public-chat:linux-arm-v7_v2

For older Raspberry Pi devices (ARM v6):

docker run -it -p 80:8080 --name public-chat pedroth/public-chat:linux-arm-v6
