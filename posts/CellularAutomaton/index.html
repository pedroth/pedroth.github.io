I made a simple Cellular Automaton application a long time ago. Here, each pixel represents a cellular automaton, which is alive if it is green and dead if it is dark. The rules for a cellular automaton to be born and to survive are defined by the S/B notation:

  • S defines the numbers of live neighbors required for a cell to survive.
  • B defines the numbers of live neighbors required for a cell to be born.

If a cell is not born or does not survive, then it dies or remains dead.

To give an example, the famous Game of Life is defined by the rule 23/3, which means that a cell survives if it has 2 or 3 live neighbors, and a cell is born if it has exactly 3 live neighbors. Note that the number of neighbors is between 0 and 8, since we are considering the 8 cells around a cell in a 2D grid.

In this app, you can try several cellular automata rules:

  • Maze: 12345/3 [key 1]
  • 34 Life: 34/34 [key 2]
  • Coral: 45678/3 [key 5]
  • Coagulation: 235678/378 [key 6]
  • Replicator: 1357/1357 [key 7]
  • Gnarl: 1/1 [key 8]
  • Flakes: 012345678/3 [key 9]
  • Totally random rules [key 0]

At the beginning, you can draw the initial state of the cells, then press the space bar to start the animation.
