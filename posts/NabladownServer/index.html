Nabladown server is a tool for visualizing nabladown files through a hot-reloading server[1].

Motivation

I wanted to write my personal notes using the nabladown markup language, but nabladown.js is a parsing and rendering library, not a file viewer. So I decided to create a tool to view these .nd files.

The main features are:

  • List local .nd files
  • Render nabladown files with hot reloading[1]
  • Dark/light themes
  • Serve media files, such as images and videos
  • Add optional custom CSS
  • Simple editor UI

For more, go check on the GitHub page.
