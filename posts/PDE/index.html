PDE is a Java application that lets you run partial differential equations (PDEs) of the form:

ut​(t,x)=f(t,x,u,∇u,∇2u)

or

utt​(t,x)=f(t,x,u,∇u,∇2u,ut​)

Here, x∈R2, uxy​=∂x∂y∂u​, ∇u=(ux​,uy​)T, ∇2u=[uxx​uyx​​uxy​uyy​​]. You may also edit the initial condition of u(0,x).

Famous equations include:

  • Heat equation: ut​=Δu=div(∇u)=tr(∇2u)=uxx​+uyy​
  • Wave equation: utt​=Δu
  • Continuity equation: ut​=−v⋅∇u,v∈R2

In the UI, there are two main fields:

  • The text input to define the initial condition, u(0,x)
  • The text input to define the PDE

In those input fields, the user can use the usual operators +, -, *, /, ^ and functions sin, cos, exp, tan, ln, .... In the PDE input, differential operators are available, such as dx, dy, d2x, d2y, dxy, dt, which correspond to ux​,uy​,uxx​,uyy​,uxy​,ut​, respectively.
