One of my first YouTube videos was about a 3D engine I made on my Casio calculator. I was bored in some high school classes and started writing lots of programs on the calculator.

The problem with this kind of software is that it only runs on the Casio, but I wanted to run it on my computer in 2023. Then I found an emulator! Emulators are amazing. They are one of the best tools for preserving software, including my Casio programs. There are many emulators, and they are very popular in the retro gaming community.

Running the emulator on my computer

First, you need to download some .g1m files and upload them to the emulator SD card. You can find some programs in my casio programs graveyard. There is one issue with the emulator: it only runs on Windows, and I use Linux. The solution was to use Wine, which can run Windows executables on Linux (also great for software preservation). Just run wine emulator_file.exe.

Hope you enjoyed my adventure through preserving old programs.
