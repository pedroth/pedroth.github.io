Lines and Surfaces is a Java application that lets you view parametrized surfaces and curves in three dimensions.

These are surfaces given by a function f:

f:(u,v)∈R2→(f1​(u,v),f2​(u,v),f3​(u,v))T

These are curves given by a function γ:

γ:t∈R→(γ1​(t),γ2​(t),γ3​(t))T

The UI accepts the usual syntax for defining functions. It supports the operators +, -, *, /, ^ and functions such as sin, cos, exp, tan, ln, .... After setting up your curve or surface, you can generate a .obj file by pressing the g key.
