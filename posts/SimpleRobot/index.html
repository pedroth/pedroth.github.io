Simple Robot is a Java application that lets you see a robotic arm following a ball. It works by performing gradient descent on a cost function. This cost function is defined as follows:

Let x∈R3 be the position of a ball, θ∈R4 be the robot's degrees of freedom (joint angles), and DK(θ)→y∈R3 be a function that receives θ and outputs y, the end position of the robot arm tip (DK is usually called the direct kinematics function). Finally, the cost function is:

θmin​∣DK(θ)−x∣2

s.tCi​(θ)>0,∀i∈{1,…,k}

Here, Ci​ are functions that constrain the degrees of freedom, e.g.: θ1​>0 and θ1​<2π.
