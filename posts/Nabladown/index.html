Nabladown.js is a parser and renderer for the nabladown.js language, which is a pseudo/flavored Markdown language.

I made Nabladown.js because I wanted a simple way to render HTML documents with formulas, code highlighting, media, etc. These are the main features of the language:

  • Simple language, like Markdown.
  • Supports mathematical formulas (LaTeX style).
  • Supports code highlighting.
  • Supports regular HTML.
  • Supports macros.
  • Exposes the parser of the language.
  • Easy way to write multiple renderers.
  • Easy to install and use.

The main motivation for Nabladown.js was rendering the posts on this website.
