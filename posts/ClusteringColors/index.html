I read here that I could access the camera from the browser, so I decided to build a small image-processing demo. One of the simplest projects is color clustering. This pixel classification creates a nice cartoonish effect.

The algorithms implemented here are K-means and a simplified Gaussian mixture model.

Details

In this demo, we try to transform each pixel from an image into a set of K representative colors. The K colors are selected to reconstruct the original image with minimal error. It is basically a compression algorithm where, instead of each pixel representing a 32-bit number, it is quantized into just K distinct colors. For example, if K=8, then each color can be encoded with 3 bits (log2​8=3) instead of 32.

We use two algorithms for this demo: K-means and a simplified version of a Gaussian mixture model.

Here we use an isotropic Gaussian, which means that the covariance matrix is a scalar multiple of the identity matrix.

The probability density function of the simplified mixture model is:

f(x)=i=1∑K​(2π)d/2σid​ϕi​​exp(−2σi2​1​∥x−μi​∥2)

Here, ϕi​ (ϕi​>0 and ∑i=1K​ϕi​=1) is the weight of the i-th Gaussian component, μi​ is the mean vector of the i-th Gaussian component, and σi2​ is the variance of the i-th Gaussian component.
